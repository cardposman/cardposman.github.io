지역 페이지 운영 기준

드롭다운은 상위지역까지만 표시합니다

상세지역이 많아질수록 상단 메뉴에 모든 지역을 넣으면 모바일 사용성이 떨어집니다. 상단 메뉴는 상위지역까지만 보여주고, 세부지역은 각 지역 페이지 안에서 선택하는 방식이 안정적입니다.

동단위 확장은 시군구 하위로 진행합니다

현재 구조는 /region/상위지역/시군구/ 형태이며, 이후 필요한 경우 /region/상위지역/시군구/동명/ 형태로 확장할 수 있습니다.
