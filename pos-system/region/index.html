매장 환경 확인

인터넷 회선, 전원 위치, 카운터 구조, 테이블 배치 등은 지역과 무관하게 먼저 확인해야 합니다.

지역 페이지 확장 준비

서울, 경기, 인천 등 지역별 세부 페이지를 추가할 때 중복 문서가 되지 않도록 고유한 기준을 정리합니다.
